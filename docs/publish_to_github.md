# Add this project to your GitHub portfolio

The package is ready for a repository. No repository has been created or
pushed on your behalf.

## Suggested repository details

- Name: `space-2024-payment-experience`
- Description: `A reproducible Python customer experience case study using ECB SPACE 2024 survey microdata.`
- Topics: `python`, `survey-analysis`, `payments`, `customer-experience`, `data-analysis`, `ecb`

## Publish

1. Extract the ZIP and open its `space_case_study` folder.
2. Run the analysis and tests using the README instructions.
3. Review the notebook, findings and carousel so you can explain the choices.
4. Create an empty GitHub repository with the suggested name. Upload the
   project files, or use Git locally as below. The `.gitignore` excludes raw
   source files, virtual environments and temporary material.

```bash
git init
git add .
git commit -m "Add SPACE 2024 payments customer experience case study"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_REPOSITORY_URL` with the URL GitHub returns for your repository.
Do not commit `data/raw/` or your virtual environment. Keep the executed
notebook, aggregate tables, figures and PDF in the repository so visitors can
review the work without running it. The source-download script recreates the
raw files with checksum verification.

## Link the work

After publishing, add your real repository URL to the LinkedIn caption and,
if desired, to your LinkedIn Featured section. The caption draft does not
invent a repository link. The carousel itself contains no placeholder URL.
